# Style Guide

The UI is a quiet writing workspace, not a marketing site.

## Visual Rules

- Use dense but readable panels.
- Use 8px radius or less for cards and controls.
- Use icons for tools and navigation.
- Keep controls obvious and keyboard-friendly.
- Avoid decorative gradients, oversized hero sections, and nested cards.
- Keep mature-story controls matter-of-fact and non-sensational.

## Component Rules

- Shared primitives live in `components/ui`.
- Workspace-specific components live in `components/workspace`.
- Components should not know database or prompt internals.
- Text must fit on mobile and desktop.
